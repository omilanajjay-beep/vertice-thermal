# VERTICE THERMAL

Luxury HVAC systems landing experience with a procedural Three.js condenser scene, GSAP interaction, partner calculator, review log, technician profiles, and Elena concierge API route.

## Run

```bash
npm install
npm run dev
```

Configure `GROQ_API_KEY`, `SENDGRID_API_KEY`, `CAL_API_KEY`, and `SENDGRID_FROM_EMAIL` in the deployment environment. The current concierge route uses Groq; Cal.com and SendGrid hooks are intentionally kept server-side for the next integration pass.
